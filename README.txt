Besplatan dvojezični WordPress uvodni blok otvorenog koda za centre koji pružaju usluge u zajednici. Free and open-source bilingual WordPress welcome block for community service centres.

== Instalacija / Installation ==

1. Instalirajte i aktivirajte ZIP kroz Dodaci > Dodaj novi > Prenesi dodatak.
2. Otvorite MOST dobrodošlica i odaberite fotografije te uredite oba jezika.
3. Bosanski blok: [welcome_block lang="bs"]
4. English block: [welcome_block lang="en"]
5. Bez lang atributa dodatak koristi jezik WordPress stranice. Without lang, the plugin follows the WordPress page locale. The legacy [most_welcome] shortcode remains supported.

Na mobitelu se prikazuje lijeva fotografija, zatim tekst i dugme, pa desna fotografija.
On mobile the order is left photo, text and button, then right photo.

Deaktivacija dodatka ne briše postavke. Deactivation does not delete settings.
